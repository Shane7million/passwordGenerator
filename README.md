Password Generator

A simple Password Generator web application built using HTML, CSS, and JavaScript.

This project was created to practice the basic software engineering process, including planning requirements, designing, coding, testing, and publishing a working website.

Project Features

Generate Password: Create a random password by clicking the Generate button.

Password Length: Choose a password length between 4 and 64 characters.

Customize Password: Choose whether to include numbers and symbols.

Copy Password: Copy the generated password to the clipboard.

Password Strength: Display a basic strength indicator for the generated password.

Technologies Used

HTML: Creates the structure of the website.

CSS: Styles the website and its layout.

JavaScript: Handles password generation and user interactions.

Visual Studio Code: Used to write and edit the code.

Git & GitHub: Used for version control and storing the project.

GitHub Pages: Used to publish the website online.

Software Development Process

I chose to follow the Waterfall model because the project requirements were simple, clear, and unlikely to change.

The development process included:

Requirements: Write five user stories to identify the main features.

Design: Create a simple application flow diagram.

Implementation: Build the website using HTML, CSS, and JavaScript.

Testing: Manually check the main features.

Deployment: Publish the project using GitHub Pages.

How to Use

Open the Password Generator website.

Select your preferred password length (4–64).

Choose whether to include numbers and symbols.

Click Generate Password.

View the generated password and its strength.

Click Copy to copy the password.

How to Run Locally

Clone the repository:

git clone https://github.com/Shane7million/passwordGenerator.git

Open the project folder in Visual Studio Code.

Open index.html using VS Code Live Server.

Start generating passwords.
